# Defense AI

Python 기반 보안 위협 탐지 및 대응 시스템 개발 프로젝트입니다.

## 구성
- `controller/`: Windows 기반 분석 및 제어
- `agent/`: Rocky Linux 기반 로그 수집 및 대응
- `common/`: 공통 데이터 구조 및 통신
- `configs/`: 공개 가능한 설정 예시
- `tests/`: 테스트
- `scripts/`: 실행 및 관리 스크립트
- `docs/`: 설계 문서

## 개발 상태
초기 프로젝트 구조 구성 단계입니다.

## 생성형 AI 활용
본 프로젝트는 개인 학습 및 포트폴리오 목적으로 개발하며, 개발 과정에서 생성형 AI를 보조 도구로 활용합니다.

- 프로젝트 설계 검토, 프로그래밍 개념 학습, 코드 리뷰, 테스트 사례 검토 및 개발 환경 문제 해결에 생성형 AI의 도움을 받았습니다.
- 공통 보안 이벤트 구조(common/event.py) 등 일부 초기 구현에는 생성형 AI가 작성한 코드가 포함되어 있습니다.
- 이후 핵심 기능의 설계·구현·테스트는 개발자가 직접 수행하는 것을 원칙으로 하며, AI의 제안은 검토와 검증을 거쳐 반영합니다.
- 생성형 AI 사용 여부와 범위는 개발 진행에 따라 이 문서에 업데이트할 예정입니다.
